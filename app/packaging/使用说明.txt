电赛工作台 Windows 便携版 —— 使用说明
==========================================

【怎么启动】
1. 把整个 zip 解压到一个路径里没有空格问题的目录（例如 D:\电赛工作台\），不要在 zip 里直接双击运行。
2. 双击「电赛工作台.exe」。
   - 需要 Windows 10/11 64 位，以及系统自带的 WebView2 运行库（Win11 和更新过的 Win10 都自带；
     打开后窗口全白或闪退，就去微软官网装「Microsoft Edge WebView2 Runtime」）。
   - 第一次启动可能被 Windows SmartScreen 拦（没有代码签名）：点「更多信息」→「仍要运行」。
   - 后台的 dzbench.exe（侧车）会自动拉起，监听 127.0.0.1:8765；防火墙弹窗选「允许」即可（只走本机）。
3. 目录里各部分：
   电赛工作台.exe   界面
   dzbench.exe     侧车（串口/仿真/调参/Agent 后台），由界面自动启动，不用手动开
   python\         随包的 Python，项目页跑读题/选型/分配/生成工程脚本用
   repo\           工作台自带的工程仓库（固件源码、工具、文档）和编好的仿真板

【怎么连仿真板（不需要任何硬件）】
1. 启动后在顶部的「连接」处打开端口下拉框。
2. 选「仿真板 · car_2wd」（或 motor_pos / pan_tilt / pendulum_rot / line_car / 2026H_ball / 2026X_follow）。
   带「+hw」的是「仿真板当实板」，用来演练确认卡和上电前检查。
3. 点连接，几秒内就会有实时曲线；之后调参、标定、评分等页面都能用仿真数据走一遍。

【已知限制】
- 这个包是在 Linux 上交叉编译、在 wine 里做的冒烟测试，还没在真 Windows 上跑过；遇到问题请把
  %USERPROFILE%\.dzbench 里的日志和报错截图发回来。
- 仿真板是预先编好的；改了 repo\ 里的固件源码后不会自动重编仿真板（Windows 上没有 make + gcc。
  要重编请装 MSYS2 的 make 和 mingw gcc）。
- 读题直接读 PDF 需要 poppler 的 pdftotext（没随包带）：把 pdftotext.exe 加进 PATH，或先把题目另存为 .txt。
- 编译烧录真板需要你自己装 Keil MDK / CCS / EIDE，烧录用 ST-Link 或 DAPLink 驱动（pyOCD/OpenOCD）；
  这些工具链太大，没有放进包里，是可选的，只用仿真板时不需要。
- 内置 Agent 要在设置里填你自己的大模型接口和密钥才能用。
- 没有代码签名，也没有自动更新。
