电赛工作台 Windows 版 —— 使用说明
==================================

【安装和启动】
1. 双击「电赛工作台_x.y.z_x64-setup.exe」，一路下一步即可。不需要管理员权限，也不需要解压软件；
   默认装到 %LOCALAPPDATA%\电赛工作台，开始菜单里有快捷方式，完成页勾上即在桌面建快捷方式。
2. 第一次运行可能被 SmartScreen 拦（没有代码签名）：点「更多信息」→「仍要运行」。
3. 需要 Windows 10/11 64 位 + WebView2 运行库（Win11 自带；Win10 缺的话安装程序会自动下载）。
4. 打开后后台侧车 dzbench.exe 自动启动，只监听本机 127.0.0.1:8765；防火墙弹窗点「允许」。

【连仿真板（不需要任何硬件）】
1. 顶部「连接」处打开端口下拉框，选「仿真板 · car_2wd」（或 motor_pos / pan_tilt / pendulum_rot /
   line_car / 2026H_ball / 2026X_follow），点连接，几秒内出实时曲线。
2. 带「+hw」的是「仿真板当实板」，用来演练确认卡和上电前检查。
3. 之后调参、标定、评分、项目各页都能用仿真数据完整走一遍。

【读题】
项目页第 ① 步可以直接选题目 PDF（内置 PDF 读取，不用装 poppler）；扫描版图片 PDF 读不出字，需先 OCR 或另存 .txt。

【安装目录里有什么】
电赛工作台.exe      界面
dzbench.exe        侧车（串口 / 仿真 / 调参 / Agent / 跑工具脚本），界面自动启动
repo\              自带的工程仓库：固件源码、工具脚本、文档、编好的 Windows 仿真板
你的数据和日志在 %USERPROFILE%\.dzbench

【已知限制】
- 仿真板是预先编好的：改了 repo\ 里的固件源码不会自动重编（要重编需装 MSYS2 的 make + mingw gcc）。
- 编译烧录真板要自己装 Keil MDK / CCS / EIDE 和 ST-Link 或 DAPLink 驱动；这些工具链很大，不在安装包里，只用仿真板时不需要。
- 内置 Agent 要在设置里填你自己的大模型接口和密钥。
- 端口 8765 被别的程序占用时侧车起不来，界面会一直显示“侧车没有响应”。
- 没有代码签名，也没有自动更新；有问题请把 %USERPROFILE%\.dzbench 里的日志和截图发回来。
