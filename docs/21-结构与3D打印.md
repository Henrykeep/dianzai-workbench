# 21 结构与 3D 打印：SolidWorks → Bambu Studio（给控制方向同学）

> 只有思路和检查清单，**没有 CAD 文件**。数字是常见经验值，打印机、材料、批次不同结果不同——**【未验证】**：每台机器先打一个公差测试件再定。模型目录约定见 docs/09。

为什么控制方向的人要管结构：机构的**刚度**决定共振频率，共振频率限制控制带宽；**间隙/回差**会让 PID 在零点附近抖；**质量/惯量**一改，整定过的参数就失效（所以 docs/09 要求标定绑定 STRUCT_VERSION）。

## 1. 建模前（拿到题目当天）
- [ ] 题目尺寸/重量/禁止项填进 `mechanical/constraints/TEMPLATE.yaml`。
- [ ] 所有买来的件**用卡尺量**（电机、编码器、摄像头、PCB），不要只信商品图：孔距、外径、轴径、D 形轴平面、线缆出口位置。量完记进零件的 PARAMS.md。
- [ ] 打印机构建尺寸（如 256×256×256 mm）——超过就要分件，先想好拼接方式（定位销 + 螺丝）。
- [ ] 决定哪些参数做成 SolidWorks **全局变量**：孔间隙、壁厚、螺丝规格、电机型号尺寸。换电机时只改变量。

## 2. SolidWorks 建模检查清单
- [ ] 单位 mm；原点放在**安装基准**（电机轴心、PCB 角孔），方便以后对位。
- [ ] 公差留在模型里，不要靠切片软件缩放：
  | 场景 | 常见起点（单边/直径） |
  |---|---|
  | M3 螺丝过孔 | Ø3.4 |
  | M3 自攻进塑料 | Ø2.6–2.8 |
  | M3 热熔铜螺母 | 按螺母规格，常见 Ø4.0–4.2，深度 = 螺母长 + 0.5 |
  | 轴与孔滑配 | 直径 +0.2–0.3 |
  | 轴与孔紧配（压入） | 直径 +0.05–0.1，先打测试件 |
  | 两件插接 | 每侧 0.15–0.2 |
- [ ] 竖直方向的孔打出来会偏小、水平孔顶部会塌：关键孔尽量让轴线**垂直于打印平台**；水平孔顶部做成“泪滴形”或 45° 尖顶，免支撑。
- [ ] 螺丝受力的地方壁厚 ≥ 3 圈线宽（0.4 喷嘴 ≈ 1.2 mm），螺丝柱外径 ≥ 2×孔径。
- [ ] 尖角改圆角（R0.5–1）：应力集中少，也不易翘边。
- [ ] 悬垂 > 45° 的面要么改倒角，要么接受支撑；支撑接触面别放在配合面上。
- [ ] 线缆通道、扎带孔、插头拔插空间（USB、SWD 下载口、电池插头）在模型里就留出来。
- [ ] 用“质量属性”估重心，和 docs/09 的估算工具交叉核对（先给材料设一个 PLA/PETG 密度，填充率按切片设置折算）。

## 3. 导出
- [ ] **STEP**（AP214）存档：通用、无损，Bambu Studio 较新版本可直接导入 STEP（以官方文档为准）。
- [ ] **STL**：选项里分辨率选“自定义”，偏差约 0.01 mm、角度约 5°；默认“粗糙”会让圆孔变多边形、配合变紧。
- [ ] 单位确认 mm（导入后尺寸差 25.4 倍 = 英寸问题）。
- [ ] 一个零件一个文件；多体零件导出前确认是否“每个实体单独保存”。
- [ ] 文件名带版本：`motor_mount_v3.STL`，与 VERSION 文件一致。

## 4. Bambu Studio 切片检查清单
- [ ] 摆放方向按**受力**选：层与层之间最弱。悬臂支架要让受力方向沿着层内（躺着打），不要让螺丝拉力垂直于层面。
- [ ] 结构件：壁 3–4 圈、顶底 4–5 层、填充 30–50%（螺旋/gyroid 或立方体）；比加填充更有效的是**加壁数**。
- [ ] 第一层：平台清洁（手印会翘边）、PEI 板选对、大平面件加圆盘（mouse ears）或 brim。
- [ ] 象脚（第一层外扩）会让底面配合变紧：开“象脚补偿”或底边做 0.4 mm 倒角。
- [ ] 支撑：树状支撑省料好拆；配合面朝上避免支撑。
- [ ] 打印前看预览：最小壁厚有没有被吃掉、孔是不是闭合了、薄壁是否只剩一圈。
- [ ] 把最终设置存进 `.3mf`，参数抄进 PARAMS.md（材料、层高、壁数、填充、方向、支撑）。

### 材料怎么选
| 材料 | 适合 | 注意 |
|---|---|---|
| PLA | 原型、相机支架、外壳 | 50–60 °C 开始软化；电机/驱动发热处会**蠕变**（螺丝慢慢松） |
| PETG | 电机座、长期受力件 | 韧性好、耐温略高，拉丝多；层间粘结好 |
| PLA-CF / PETG-CF | 需要刚度的长臂、云台 | 更硬更脆，用硬化喷嘴 |
| ABS / ASA | 靠近热源、户外 | 需要封闭机箱，易翘曲 |
| TPU | 减震垫、防滑轮胎 | 慢速打印 |

## 5. 各类安装座要点
### 5.1 电机座
- [ ] 定位靠**止口/凸台**（电机前端的圆台）对中，螺丝只负责压紧；N20、JGB37-520、42 步进的凸台和孔距各不相同，按实测画。
- [ ] 42 步进（NEMA17）常见：孔距 31 mm、凸台 Ø22 mm、M3——**仍以实物为准**。
- [ ] 安装面厚度 ≥ 4–5 mm，背后加筋；电机扭矩反作用力会让薄板扭，表现为控制里的“软弹簧”。
- [ ] 电机会发热：PLA 座子跑久了会松，改 PETG 或加金属垫片；螺丝用热熔螺母，不要直接自攻（反复拆装会滑牙）。
- [ ] 联轴器/轮子与电机轴同心：轴孔紧配 + 顶丝压在 D 面上，留顶丝工具的操作空间。

### 5.2 编码器
- [ ] 磁编码器（如 AS5600 类）：径向磁化磁铁对准芯片中心，偏心 < 0.5 mm 左右，气隙按芯片手册（常见 0.5–3 mm）；做一个**可调气隙**的结构（垫片或长孔）。
- [ ] 光电/霍尔编码器随电机自带的：注意排线弯折半径，别让线缆拉扯码盘。
- [ ] 外置编码器跟随传动轴：用柔性联轴器，刚性连接 + 不同心会周期性误差（速度曲线上出现与转速同频的波纹）。
- [ ] 编码器座和电机座做成**同一个零件**，减少装配误差累积。

### 5.3 摄像头
- [ ] 高度、俯仰角做成**可调**（长槽孔或分度孔），调好后把实际角度和高度记进 calib.yaml——它直接决定 mm_per_px。
- [ ] 刚度第一：摄像头支架晃 1 mm，远处目标就晃好几个像素，视觉环会被“抖”出振荡。长杆用 CF 材料或铝管 + 打印接头。
- [ ] 镜头前留遮光罩位置；避免支架本身出现在画面里（先用手机拍一张模拟视场）。
- [ ] 线缆用扎带固定在支架上，防止运动时拉扯镜头角度。
- [ ] 改了摄像头支架 → STRUCT_VERSION 升版 → 重新标定。

### 5.4 PCB 安装柱 / 主控
- [ ] 用 M3 铜柱/尼龙柱，PCB 离底板 ≥ 5 mm（底面焊点不碰结构，空气流通）。
- [ ] 孔位从 PCB 文件或实测取，**留 0.3–0.5 mm 余量**做成稍大的孔或长孔，方便装配。
- [ ] USB、SWD/下载口、BOOT/复位键、拨码开关、电池插头在装好后仍能碰到——比赛现场改参数靠它。
- [ ] IMU：尽量靠近转动中心、刚性安装、与车体坐标轴对齐（偏 3° 就会带来约 0.5 m/s² 的假加速度，见 dzimu 去重力说明）；电机附近的振动用 TPU 垫隔离要谨慎——太软会让 IMU 和车体不同步。
- [ ] 电源线、电机线和信号线分开走，驱动板远离 IMU 和摄像头排线。

## 6. 装配后、上控制之前
- [ ] 手拨一遍：有没有回差（反向时空行程）、卡滞、异响。
- [ ] 称重、找重心（悬挂法），和模型对照，差 > 10% 说明模型漏了零件（电池、线）。
- [ ] 敲一下（或给阶跃）听/看结构的振荡频率；控制带宽建议远低于它（常见经验：低 3–5 倍）。
- [ ] 记录 STRUCT_VERSION，跑一遍开环阶跃（工作台“阶跃实验”）留档，再开始调 PID。
