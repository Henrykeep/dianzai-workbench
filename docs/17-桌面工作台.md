# 17 桌面工作台（dzbench）

> 场景：比赛现场、时间紧、队友第一次用。目标是**插上就能看曲线、改参数、随时急停**，出错时告诉你怎么修。

## 一分钟上手
```bash
pip install -r app/sidecar/requirements.txt          # pyserial websockets pytest
(cd app/ui && npm ci && npm run build)
PYTHONPATH=app/sidecar python3 -m dzbench --ui app/ui/dist   # 浏览器打开 http://127.0.0.1:8766/
```
- 没有硬件：端口选 **仿真板 · car_2wd / 2026H_ball**（host-sim 跑真实固件逻辑，自动 `make`），界面与真板完全一样。
- 有硬件：插 USB 转串口，端口会自动出现并选中；波特率默认“自动”。
- Windows 安装包：`.github/workflows/app-windows.yml` 手动触发（**未测**，见下文）。

## 架构
```
 ┌──────── Tauri 外壳（只开窗、拉起/收掉侧车）────────┐
 │  UI：Vite + TS + uPlot（app/ui）                    │
 └───────────────▲─────────── WebSocket JSON ─────────┘
                 │ ws://127.0.0.1:8765
 ┌───────────────┴──── Python 侧车 dzbench（app/sidecar）────────────────┐
 │ transport（串口 / sim:<app> / 回放） → dzlink.Parser → session          │
 │ schema（按心跳哈希匹配 link_schema.json） downsample（min-max 60 Hz）   │
 │ logfile（.dzlog 原始全量）snapshots  agent_api（只读 + 提议）           │
 └───────────────▲──────────────────────────────────────────────────────┘
                 │ dzframe/1（与固件同一实现：host/python/dzlink）
       板子：dzctl（参数表/限幅/急停锁存）+ link_gen（gen_link.py 生成）
```
- 协议逻辑全在侧车，可脱离界面用 pytest 测；界面只是渲染 + 按钮。外壳坏了也能用浏览器模式。
- 侧车不抽稀地把原始字节写进 `~/.dzbench/logs/run_*.dzlog`，给 UI 的才抽稀（每 16 ms 每通道 ≤200 点，桶内取 min/max，毛刺和超调峰值不丢）。

## 板端协议（dzctl，firmware/proto/dzctl）
| 帧 | 方向 | 内容 |
|---|---|---|
| HEARTBEAT | 板→PC 500 ms | u32 schema 哈希（FNV-1a32，gen_link.py 生成） |
| DATA id=遥测 id | 板→PC | link.telemetry 字段（小端紧凑） |
| PARAM_SET id=参数序号 | PC→板 | len 0 = 读；len 4 = 写 f32 |
| PARAM_ACK | 板→PC | u8 状态（0 OK/1 CLAMPED/2 BAD_ID/3 BAD_LEN/4 BAD_VALUE）+ f32 实际值 |
| DATA 0x7F | PC→板 | 急停（锁存，直到 CMD 'R'） |
| DATA 0x7E | PC→板 | 命令：u8 字符 [+ u8 参数] |

参数协议借鉴 MAVLink 参数微服务（按索引读写、写后回显实际值）与 PX4 参数元数据（min/max/unit 在生成期给出）。

## WebSocket 协议（app/sidecar/dzbench/server.py）
UI→侧车 `{"op", "rid", ...}`，回 `{"type":"reply","rid","ok","data"|"error"}`。错误统一为 `{code, message, fix}`，界面原样显示“怎么办”。

| op | 说明 |
|---|---|
| hello / list_ports | 端口（串口 + 仿真板）、当前状态、schema、参数、快照 |
| connect {port, baud:"auto"\|数字} / disconnect | 自动波特率：依次试 460800、921600、115200…每个听 250 ms，收到合法帧即停 |
| estop | 连发 3 帧；未连接/回放中**如实**说没送达 |
| cmd {c, n} / send_data {id, hex} | 板端命令 / 应用自定义 DATA（如 car_2wd 轮速设定） |
| param_set / param_read_all | 侧车先限幅，再等 ACK（250 ms × 3 次重发） |
| snapshot_save / snapshot_list / snapshot_restore {name \| defaults} | `~/.dzbench/snapshots/<哈希>/`，换固件不会串 |
| log_list / replay {path} | 回放走同一条解析路径 |
| propose / proposal_decide / agent_tool | Agent 接缝（下节） |
| raw_monitor {on} | 开/关原始监视器推送 `raw`：`c=[[t, 方向 0收/1发, hex]...]`，每 1/60 s 最多 16 KB，积压超 256 KB 丢最旧并计入 `raw_dropped` |
| auto_reconnect {on} | 串口意外断开后按 0.25/0.5/1/2/4 s 退避重开同一口；主动断开/仿真/回放不重连；重连成功推 `reconnected` 并重读参数 |
| fft {field, seconds} | 频谱：取最近 seconds 秒，按 schema `telemetry.period_ms` 定采样率（与实测间隔差 >20% 或有丢帧会警告），去直流、Hann 窗、N=2 的幂 ≤4096，单边幅值已做窗修正；返回前 3 个峰 |
| replay_ctl {seek, speed, pause} | 回放时间轴：跳到第 seek 秒（清旧样本，推 `seeked`）、0.05–20 倍速、暂停 |
| log_export {path} | .dzlog → 同名 .csv（UTF-8 BOM、`t_s` + 各字段，枚举多一列文字） |
| tune_analyze / agent_ask / yaml_writeback / change_decide / rollback … | 内置 Agent，见 docs/18 |

推送：`status`(4 Hz)、`telem`(60 Hz)、`schema`、`param`、`proposal`、`error`、`estop`、`raw`、`reconnected`、`change`、`agent_tool`。

## Agent 接缝（Agent 本体见 docs/18）
`agent_api.AgentTools`：`read_telemetry(seconds)`、`list_params()`、`propose_param_change(name, value, reason)`。
- 工具定义是 JSON Schema（`TOOLS`），可直接映射为 MCP / function calling。
- **Agent 不能直接写参数**：提议变成界面卡片，人点“采纳”后走与手动修改相同的限幅/ACK/日志路径；急停只属于人。测试 `test_websocket_server` 断言了“提议不生效，采纳才生效”。

## 界面要点
- 急停：右上红键，`Space`（不在输入框时）或 `Esc`（任何时候）；侧车断开时也能点，并提示“未送达，立刻断电”。
- 参数：改了没下发的格子是橙色；`Enter` 下发单项，`Ctrl+Enter` 全部；`↑/↓` 按量程 1% 微调（Shift ×10）；超范围先在界面限幅并提示，板端还会再限一次。
- 快照：`Ctrl+S` 存、列表一键恢复、“恢复默认”= 固件编译时默认值。
- 曲线：2/5/10/30 s 窗口、`P` 暂停、点通道名开关；枚举通道（如 `state`）以文字显示。
- 新插的串口自动选中并提示；ttyS0/COM1 这类板载口不默认选。
- 原始视图：曲线面板右上“原始”，文本/HEX 切换，非工作台固件的设备（视觉模块 printf、蓝牙 AT）手动选波特率连上即可看。
- 线松了：自动重连，链路显示“重连中…”；此时急停送不到板子（板端应靠心跳超时自停，见 QUESTIONS 决定 1）。
- 频谱视图：曲线面板右上“频谱”，选通道和窗口，峰值标出频率——振荡 3 Hz 还是 25 Hz 决定了是减 Kp 还是查机械/滤波。
- 回放：底栏时间轴可拖动、暂停、倍速。
- 底栏“导出 CSV”：选中的记录转 CSV，Excel 直接打开。
