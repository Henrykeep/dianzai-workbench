# 极性自检（agent/polarity.py，op polarity_check）
- 正反馈的典型症状：一闭环就冲到限幅、误差越来越大。先别调 PID，先查四个符号：传感器轴、误差定义、控制器、执行器。
- 手推（观察模式，不发指令）：往正方向推，看测量值是否增大 → 传感器轴；看误差和控制量的符号 → 误差/控制器。
- 点动：给小正控制量，看测量值变化 → 执行器方向。四个符号乘积为负才是负反馈；结论会指出哪一处反。
- 判据带噪声显著性检查（一段内的变化量要大于 3 倍残差噪声才算“动了”），死区里抖动不会误判。
