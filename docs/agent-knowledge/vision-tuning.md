# 视觉现场调参顺序与对症
1. 锁曝光/白平衡（或固定自动曝光行为）→ 2. 原始画面对比度够不够 → 3. 低分辨率阈值 → 4. 滤波核、边缘阈值 → 5. 几何门 → 6. 跟踪平滑与丢失外推 → 7. 显示坐标映射 → 8. 主控端核对串口字节 → 9. 每改一步测一次 FPS。
- FPS 低：先降**识别通道**分辨率（不是降显示）；叠加层每 2–4 帧画一次或关掉；限制候选数；颜色校验只在 ROI 里做；用 cv_lite/OpenCV 原语替代 Python 像素循环；只处理最新一帧。
- 抖：加中心/角点时间平滑、中心死区；锁定后收紧候选门；重新捕获和跟踪分开。
- 丢目标：放松阈值、扩大 ROI 余量、加备用通道（灰度边缘 + 颜色/面积校验）；只有误锁比漏检更糟时才加确认帧数。
- 运动模糊（钢球）：先提高源帧率、缩短曝光、补光、缩小识别通道，再考虑更重的算法；快速横移漏检时逐步调大 Kalman 加速度噪声和预测门。
- 串口不对：先把视觉对不对和协议对不对分开。低频打印帧字节，核对字节序、校验、坐标系、缩放、发送节拍；带有效/丢失标志或心跳。本仓库用 dzframe/1，主机端 `python -m dzlink.latency stats` 看帧率、丢帧、抖动。
- 每轮结束只要一个可量化反馈：FPS、锁定稳不稳、误差方向、帧字节或失败视频。
