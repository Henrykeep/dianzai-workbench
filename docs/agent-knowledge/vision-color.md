# 颜色识别流程（视觉）
- 默认链路：低分辨率识别帧 →（可选灰度世界白平衡）→ 3×3 高斯 → 阈值掩膜 → 开一次（断了再闭一次）→ 连通域/轮廓 → 几何筛选 → 时间一致性 → EMA/α-β 平滑 → 串口输出。高分辨率只用于锁定后的 ROI 精修。
- 色彩空间：光照稳用 RGB（最快，cv_lite rgb888_find_blobs）；亮度变化用 HSV/LAB/YCrCb。**HSV 红色跨 0°，必须两段 H 范围取或**，再加 S/V 下限去掉白色反光。
- 激光点/LED：已知颜色先预筛 → 取 V/Y/L 亮度通道 → Otsu（每 N 帧算一次 + EMA 防跳）→ 背景不匀用 top-hat → 选最亮的小斑。
- 几何门：面积/像素数范围、长宽比、填充率（轮廓面积/外接框）、凸度、圆度 4πA/P²、半径范围、贴边的不信、色纯度、锁定后离预测位置的距离、≥2 帧稳定才锁。
- 排错先后：小噪点→高斯+开；线断→闭/膨胀一次；背景不匀→top-hat 或亮度 Otsu；颜色漂→锁曝光/白平衡；抖→EMA/死区，再不行 α-β/Kalman。核从 3×3 一次开始，每加一步测 FPS。
- 本仓库：MaixCAM 侧 `host/maixcam/ball_tracker.py`（ROI + 颜色阈值 + α-β）；K230 侧见 vision-k230 知识。
