- F4 写回卡片顶部列出“名字 旧 → 新”。

## 未修与下一步（按对“90% 快速做完 + 少花时间”的贡献排序）
1. **M1 题目验收口径**（最高）：把“误差带（物理单位）+ 速度阈值 + 持续时间 + 总时限 + 多段目标”写成 schema/dzbench.json 里的可选 `accept`，读数条和台账直接显示“通过/不通过、到位用时、全程最大误差”，台账按“连续 N 次的最差一次”汇总。原因：评委只看这个；现在参赛者要自己掐表、自己看曲线判断。
2. **F6 门禁口径**：写回参数默认值时，行为测试（玩具模型）失败是否允许“标注后仍提交”。需要用户决定（已记入 QUESTIONS）。
3. **单位标定**：px → cm（两点/多点线性）声明在 schema，读数直接用题目单位。2026H 的误差要求是 1 cm。
4. 串级逐层调（角度环 → 速度环 → 位置环）的向导：每层单独阶跃、单独台账；参考资料一致强调“内环不稳禁止进入下一层”。
5. F11/F12/F7 诊断。
