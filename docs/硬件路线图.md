# 硬件路线图

> 标注约定：**【已实测】** = 本仓库在 PC 上用测试/编译实际跑过（2026-10-28，Asia/Shanghai）；**【未验证】** = 设计意图或推断，尚未在真实硬件上做实验。实验是检验真理的唯一标准——【未验证】的内容上板前不要当结论。

| 板卡 | 芯片 | 移植层 | 状态 |
|---|---|---|---|
| host-sim | PC | host-sim | 【已实测】全部主机测试 |
| stm32f407-skystar（立创·天空星） | STM32F407VET6 或 VGT6（part=TODO，看丝印） | stm32f4-hal | 【已实测】交叉编译；【未验证】上板；KEY/USART 引脚待用户核对 |
| stm32f407-skystar-cubemx | STM32F407VETx（合成样例） | stm32-cubemx | 【已实测】交叉编译；【未验证】合成 .ioc，需真实 CubeMX 打开 |
| dji-rm-c（RoboMaster 开发板 C 型） | STM32F407IGH6 | stm32f4-hal（与天空星共用 F4 层） | 引脚取自 DJI 官方用户手册；hse_hz=TODO（手册未确认 12 MHz 前不生成固件）；KEY 极性 TODO；CAN/SPI(BMI088)/I2C(IST8310)/DBUS 记在 todo，待 schema 扩展 |
| mspm0g3507-tianmengxing（立创·天猛星） | MSPM0G3507 | mspm0-driverlib（预留） | 仅占位，引脚/.syscfg TODO |
| jetson-nano-vision | NVIDIA Jetson Nano | 协处理（dzlink） | 【已实测】协议回环；【未验证】真机串口/帧率/ssh |
| FPGA / 软核 | — | fpga_logic / 新移植层 | 预留 |

后续阶段：board schema 增加 can/spi/i2c 类型 → dji-rm-c 的 BMI088、CAN 电机（M3508/GM6020）驱动；参考 RoboMaster C 型例程。
