# 03 模块三件套与版本

> 标注约定：**【已实测】** = 本仓库在 PC 上用测试/编译实际跑过（2026-10-28，Asia/Shanghai）；**【未验证】** = 设计意图或推断，尚未在真实硬件上做实验。实验是检验真理的唯一标准——【未验证】的内容上板前不要当结论。

每个可复用模块目录必须有：
1. **README.md**：职责、接口、自检方法、验证状态（已实测/未验证）、参考来源。
2. **VERSION**：`MAJOR.MINOR.PATCH`，与头文件 `XXX_VERSION` 宏一致（check_deps V1）。
3. **selftest**：`xxx_selftest()` 函数（纯逻辑模块可在主机单测里调用；驱动的 selftest 需上板）。

## 版本规则（语义化版本）
| 变化 | 版本 |
|---|---|
| 删除/修改已有公开声明（破坏兼容） | MAJOR+1 |
| 只新增声明 | MINOR+1 |
| 声明不变（修 bug、改实现） | PATCH+1 |

`tools/iface_hash.py --check` 抽取公开头文件声明与 `iface.lock.json` 对比，违规时 `make check` 失败；`--update` 只在合规时刷新锁文件。
- 【已实测】`iface_hash --selftest`：故意改 pid 函数签名不升版本，会被拦住。
- 【已实测】本阶段 coord、dzframe 新增 selftest 函数，按规则升到 1.1.0 并通过检查。
