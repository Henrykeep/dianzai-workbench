# 早上看这一页就够了

按优先级排。所有“[未测]”的东西都只在电脑仿真或编译里跑过，真板上的表现要靠你带板子来验证。问题编号对应 `docs/QUESTIONS.md`。

## 一、先做（10 分钟，不用硬件）
1. **装一下 Windows 安装包**：GitHub Actions 里最新一次运行的 `dzbench-windows`。打开后选 `sim:car_2wd`，看能不能连上、出波形、按急停。打不开或者报错就截图给我。
2. **翻一眼下面“要你拍板”的几条**，不同意的直接说。

## 二、要带的东西
1. **天猛星的原理图，或你实际用的 .syscfg**：现在的引脚是按公开资料推的，超声波、VBAT 这些脚都没对过原理图。
2. **天空星 + ST-Link**：用来第一次真板烧录，验证编译 → 烧录 → 心跳哈希核对这条链路。
3. **DJI C 板**：烧之前看一眼晶振上的丝印，我按 12 MHz 配的（28）。
4. **QD4310 驱动板的手册**（或者能抓包的环境）：CRC-8 初值还没确认（9）；顺便告诉我这份资料能不能放进仓库（12）。
5. **MaixCAM2**：确认串口设备名（12），用万用表量一下排针 UART 是不是 3.3 V。
6. **如果能找到：比赛的最终版工程**。现在 2026H 的参数来自非最终版代码，全部标着未验证。

## 三、要量的东西（按顺序）
1. **电池分压比（45，最重要）**：天空星的 VBAT 还写着 1/1，这样**电池过放保护实际上是关着的**。量一下分压电阻，比如 10k/1k 就填 11/1。天猛星板上没有分压，需要你自己焊。
2. **编码器 counts_per_rev**：让轮子转 10 圈，看计数总数，除以 10。
3. **左右轮对应关系（11）**：发一个小的前进指令，看 A 轮是左轮还是右轮，以及两个轮子是不是都往前转。
4. **beam_dir（10）**：摆杆角度给正值时，钢珠应该往相机 x 正方向滚；方向反了就把 beam_dir 改成 -1。
5. **电池急停实测**：用可调电源从 8.2 V 慢慢降到 6.5 V 以下，车应该锁住急停，电压升回去也不会自己解除，要按 R 才行。
6. **FreeRTOS 板（学长那块 F407）**：遥测里看 `cpu_pm` 和 `stk_min_w` 有没有读数；栈余量低于 32 字就要加栈。CPU 负载要先在 CubeMX 里打开 GENERATE_RUN_TIME_STATS（47）。
7. **视觉延迟和帧率**：用工作台的延迟工具量一下，填进 maixcam2 board.yaml 的 rate_hz。

## 四、要你拍板（我先定了，不同意就改）
- **24 不稳定的判定标准**：现在只有振荡超过 2 次或超调超过 40% 才算不稳定，响应慢不算。你想更保守，就告诉我改回“慢也算不稳定”。
- **19 真车上回退到最佳参数**：仿真里自动回退，真车上要你点一下才执行。要不要“按急停时自动回退”？
- **32 没填 Key 时**：自动换成离线助手。你更想要直接提示去填 Key 吗？
- **27 MSPM0 的 I2C/SPI**：天猛星已经接上了，但没上板。需要先测哪一路？
- **2026H 的小题和限时**：project.yaml 里现在是示例，按官方题目原文改一下，或者把题目发给我。
- **各板子下载器配置**：openocd_interface 还空着，你用 ST-Link、队友用 DAPLink，我按这个填可以吗？
