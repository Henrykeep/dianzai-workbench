# 02 分层与依赖

> 标注约定：**【已实测】** = 本仓库在 PC 上用测试/编译实际跑过（2026-10-28，Asia/Shanghai）；**【未验证】** = 设计意图或推断，尚未在真实硬件上做实验。实验是检验真理的唯一标准——【未验证】的内容上板前不要当结论。

```
apps/ examples/<题目>（io 胶水、子系统、project.yaml）
        │
firmware/drivers   （motor_dc、encoder：只依赖 pal）
firmware/framework （subsys 调度器、coord 协调器：不碰硬件）
firmware/algo  firmware/proto （pid、lpf、dzframe：纯 C）
firmware/pal       （接口）
firmware/common    （dz_err）
────────────────── 以上与芯片无关 ──────────────────
ports/<移植层>     （host-sim / stm32f4-hal / stm32-cubemx / mspm0-driverlib[预留]）
boards/<板>/board.yaml → tools/gen_board.py → board_gen.{h,c,mk}
```
只能向下依赖。**移植层按芯片系列共享，board.yaml 按板卡区分**（例：天空星 F407 与 RoboMaster C 型共用 F4 移植层）。

## check_deps 规则（`python3 tools/check_deps.py`，`make check` 自动运行）
| 规则 | 内容 |
|---|---|
| L1 | 分层 #include 白名单 |
| L2 | 厂商 API/头文件只能出现在 ports/ |
| L3 | host_sim.h 只能在 host-sim、tests、sim_setup.c |
| S1 | 子系统不得 include pal/board_gen/驱动/io/其它子系统 |
| S2 | 子系统只写自己 owns 的共享状态段 |
| P1 | STM32 只许 CubeMX+HAL；禁标准库；禁直接写寄存器（除非 `DZ-REG-OK: 原因`） |
| P2 | HAL/LL 只在 ports/stm32*，DL_ 只在 ports/mspm0* |
| C1 | CubeMX 生成目录：允许 HAL，USER CODE 只放框架接缝 |
| I1 | GPIO 中断回调（pal_gpio_irq_attach 的回调）只计数 / 记时间戳：不许 printf、延时、串口发送、malloc、OLED、浮点数学函数、循环 |
| V1 | VERSION 文件与 XXX_VERSION 宏一致 |

- 【已实测】`check_deps.py --selftest` 用 tools/fixtures/deps_* 违规样例证明每条规则都能拦住。
- 【未验证】规则基于正则，不是完整 C 解析器：宏拼接等“刻意绕过”拦不住，靠代码评审兜底。
