# 09 机械结构

> 标注约定：**【已实测】** = 本仓库在 PC 上用测试/编译实际跑过（2026-10-28，Asia/Shanghai）；**【未验证】** = 设计意图或推断，尚未在真实硬件上做实验。实验是检验真理的唯一标准——【未验证】的内容上板前不要当结论。

2026 H 题的教训：机械结构和 3D 建模与软件同样决定成败。本阶段只做目录与流程预留（`mechanical/`）。

## 1. 题目约束 → 检查清单
`mechanical/constraints/TEMPLATE.yaml`：把题目里的尺寸、重量、材料、禁止项、场地条件逐条写成可勾选项（来源条款号、限值、实测值、测量方法、结论）。拿到题目第一天填写，每次改结构后重新勾选。

## 2. 估算工具（mechanical/calc/，预留）
- 重心：各零件质量 × 位置加权（SolidWorks“质量属性”可直接给出，用于交叉核对）。
- 转动惯量：常见形状公式 + 平行轴定理；用于整定 PID 与选电机。
- 扭矩：τ = J·α + m·g·r·sinθ + 摩擦，乘安全系数（建议 ≥ 2）选电机/舵机。
- 【未验证】所有估算必须用实测核对（称重、悬挂法找重心、阶跃响应辨识）。

## 3. 参数化模型库（mechanical/models/）
建模软件：**SolidWorks**；打印：**拓竹 Bambu Lab**。每个零件一个目录：
| 文件 | 用途 |
|---|---|
| `<零件>.SLDPRT` | SolidWorks 源文件（参数用“方程式/全局变量”） |
| `<零件>.STEP` | 通用交换格式，其它 CAD 可打开 |
| `<零件>.STL` | 打印网格 |
| `<零件>.3mf` | Bambu Studio 工程（含切片设置） |
| `PARAMS.md` | 参数说明 + 打印参数（材料、层高、壁数、填充、支撑、摆放方向），模板 `models/PARAMS_TEMPLATE.md` |
| `VERSION` | 零件版本 |
二进制文件走 Git LFS（`mechanical/.gitattributes`）；`~$*`、`*.SLDBAK` 已忽略。

## 4. 结构版本与标定/参数绑定
- 装配体 `assemblies/<名>/STRUCT_VERSION`；任何影响尺寸/质量/传动比的修改都要升版本。
- 标定与控制参数（mm_per_px、counts_per_rev、PID 增益）记在 `calib.yaml`，写明对应的 STRUCT_VERSION；结构升版后旧标定视为【未验证】，需重新标定。

## 5. 建模与打印清单
SolidWorks → Bambu Studio 的检查清单、材料选择，以及电机/编码器/摄像头/PCB 安装座要点见 **docs/21-结构与3D打印.md**。
