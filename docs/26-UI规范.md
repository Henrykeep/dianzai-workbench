# 26 · UI 规范

适用于 `app/ui`。变量在 `src/tokens.css`，组件样式在 `src/style.css`。规则只有一条：**新界面只组合已有变量和组件；需要新的就先改这份文档。**

## 参考与取舍

| 参考 | 学到的 | 没采用的 |
|---|---|---|
| VOFA+ / Serial Studio | 曲线占主区，通道列表可一键显隐，原始数据随手可看 | 仪表盘堆满小部件（信息密度太低） |
| PlotJuggler | 拖选缩放、通道搜索、回放进度条 | 多标签页布局（比赛现场太重） |
| SerialWeb（只看思路） | 预设命令一键发送 | — |
| Betaflight Configurator | 危险操作前的检查清单（prearm）、改动先“待写入”再下发 | 左侧大导航 |
| VS Code | 三栏 + 底部状态栏；少用的功能收进“…”菜单 | 活动栏 |
| Linear / Raycast | 中性灰阶、一个强调色、8 px 圆角、细线代替粗边框 | — |
| Arc / Figma | 弹出菜单的层级感：阴影 + 1 px 描边，140 ms 过渡 | 大面积毛玻璃（费 GPU） |
| Grafana dark / Foxglove | 深色下状态色要降饱和；读数用等宽数字 | — |

## 信息层级

1. **曲线和急停**：曲线占中间最大块；急停是全界面唯一的实心红块，永远在右上角，按 Space 触发。
2. **参数和 Agent**：右栏，上参数下 Agent。等你确认的卡片带强调色描边。
3. **其他都折叠**：串口细节（波特率 / 行协议 / 自动重连）在连接旁的 ⚙ 菜单；板子命令在左栏“板子命令”里；规则 / 撤销 / YAML / 新对话 / 守护 / 编译烧录回滚 / Agent 设置在 Agent 的“…”菜单；自检和主题是顶栏的图标按钮。功能一个没删。

## 通用，不认题目

核心界面不写任何具体题目的字段名。题目相关的展示全由 schema 声明：

- 枚举字段（`enum:`）在左栏显示为文字状态；`RUNNING/VALID/HELD/LOST/ESTOP/FAULT/DONE` 自动上状态色。
- 字段加 `pin: <标签>` 就会出现在顶栏读数区，`pin_with: [字段…]` 附带显示数值。例：视觉链路 `pin: 视觉, pin_with: [vis_age_ms, vis_drops]`；通信链路、模式、标定状态同理。
- 参数的范围、单位、描述来自 schema；Agent 卡片的内容来自工具返回。

## 网格与间距

- 4 px 基础单位，间距只用 `--sp1..5` = 4 / 8 / 12 / 16 / 24。
- 外框：顶栏 48、状态栏 28；主区三栏 216 / 自适应 / 384，栏间距 8。≤1280 px 时两侧栏收窄到 184 / 340。
- 控件高 28（`--h-ctl`），紧凑控件 24（`--h-sm`）；面板标题栏 44。

## 字体

- 无衬线：Inter Tight（随包）→ 苹方 / 鸿蒙 / 微软雅黑 / 思源黑体。中文用系统字体，不打包 CJK 字体（太大）。
- 等宽：JetBrains Mono（随包），所有数值用 `tabular-nums`，跳动时不抖。
- 字阶只有 5 级：11 标签 / 12 小正文 / 13 正文 / 14 标题 / 20 读数。标签用正常大小写的无衬线，不用全大写字距。

## 颜色

- 表面 4 层：`--s0` 背景 → `--s1` 面板 → `--s2` 卡片/弹层 → `--s3` 控件；层级靠明度差和 1 px 半透明描边（`--hair`/`--line`），不用粗边框。
- **强调色只有一个**（靛蓝 `--acc`）：主按钮、选中、焦点环、待下发的参数。从橙色换成靛蓝，是为了不和警告黄 / 急停红抢。
- **状态色只表示状态**：`--ok` 绿、`--warn` 黄、`--crit` 红、`--info` 蓝，各有一个 12% 底色。不拿来做装饰。
- 急停红 `--estop` 只用于急停按钮。
- 通道色：第 1 条用最高对比的前景色，其余按 Okabe-Ito（色盲可分），第 5 条起加虚线。
- 浅色主题（顶栏 ☀ 按钮，记在本地）给户外强光用，所有变量同名覆盖，曲线跟着重绘。

## 层次与动效

- 阴影 3 级：`--sh-1` 控件、`--sh-2` 面板、`--sh-pop` 弹层/对话框/提示。
- 圆角：4 小件 / 6 控件 / 8 卡片 / 10 面板。
- 过渡统一 140 ms `--ease`，只动颜色、透明度和 4 px 位移；尊重 `prefers-reduced-motion`。
- 焦点：键盘焦点统一 2 px 强调色光环（`:focus-visible`），鼠标点击不出现。

## 组件

| 组件 | 类 | 规则 |
|---|---|---|
| 按钮 | `.btn` `.pri` `.ghost` `.sm` `.icon` | 一个区域最多一个 `.pri` |
| 输入 | `.in` `select` | 改了没下发加 `.chg` |
| 分段 | `.seg` | 2–4 个互斥选项 |
| 菜单 | `details.menu > summary + .pop > .mi` | 点外面 / Esc / 点菜单项都收起 |
| 面板 | `.panel > .ph` | 标题 13 px 半粗 |
| 卡片 | `.card > .hd .act` | 等你点的卡强调色描边；处理完 `.done` 变淡 |
| 提示 | `.toast.ok/.info/.warn` | 左侧 3 px 状态色条 |
| 空状态 | `.empty` | 一句说清下一步做什么（“选一个串口或 sim:…，点连接”） |

图标：Lucide（MIT），按需 import，16 px / 1.75 描边，没有字的图标按钮必须有 `title`。

## 性能

无 UI 框架；样式 ~50 kB（含字体声明），JS ~100 kB。曲线 uPlot。新增依赖只有 `lucide`（按需打包，用到的 15 个图标）。
