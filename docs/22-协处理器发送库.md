# 22 协处理器发送库（dzlink 1.1.0）

视觉/算力板（Jetson Nano、树莓派、地瓜 RDK、MaixCAM/MaixCAM2、K230）把识别结果发给 MCU，统一走 dzframe/1（帧格式见 [08 协处理板与软核](08-协处理板与软核.md)）。
MCU 端用 `tools/gen_link.py` 按 board.yaml 的 `channels` 生成解包代码；协处理器端用本库打包。两边按同一份通道定义，字段顺序、类型一致。

| 平台 | 运行环境 | 用哪个 | 默认串口（【未验证】以各家文档为准） |
|---|---|---|---|
| Jetson Nano | Linux + CPython | `host/python/dzlink` | `/dev/ttyTHS1`（40-pin 8/10 脚） |
| 树莓派 3/4/5 | Linux + CPython | `host/python/dzlink` | `/dev/serial0`（先 `raspi-config` 关串口登录、开硬件串口） |
| 地瓜 RDK X3 / X5 | Linux + CPython | `host/python/dzlink` | `/dev/ttyS3`（X3）/ `/dev/ttyS1`（X5） |
| MaixCAM / MaixCAM2 | Linux + MaixPy（CPython） | `host/python/dzlink`（自动用 `maix.uart`） | `/dev/ttyS0` |
| K230（CanMV） | MicroPython | `host/k230/dzsend.py`（单文件） | `machine.UART(2)`，引脚用 FPIOA 配 |
| 任意 + USB-TTL | — | 同上 | `/dev/ttyUSB*`、`/dev/ttyACM*`、Windows `COMx` |

## 1. 安装
```bash
# Linux 板（Jetson / 树莓派 / RDK）：只要标准库 + pyserial
pip3 install pyserial
scp -r host/python/dzlink  user@板子:~/      # 或 git clone 整个仓库
# MaixCAM：把 dzlink/ 目录拷到 /root/（MaixPy 自带 maix.uart，不需要 pyserial）
# K230：把 host/k230/dzsend.py 拷到 /sdcard/
```

## 2. 串口自动探测
```bash
python3 -m dzlink.autodetect
# 平台: jetson  候选: ['/dev/ttyTHS1', '/dev/ttyUSB0']  选择: /dev/ttyUSB0（收到 MCU 的 dzframe（已确认））
```
规则：`DZ_SERIAL` 环境变量最优先 → 平台 40-pin 默认口 + 所有 USB 串口逐个监听约 1.2 s，收到合法 dzframe（MCU 每 500 ms 发 HEARTBEAT）就选它 →
都没收到时返回平台默认口并标“未确认”。没确认时按顺序查：TX↔RX 交叉、**共地**、两边波特率、3.3 V 电平（Jetson/树莓派 40-pin 不耐 5 V）。

## 3. 发数据
```python
from dzlink import Sender
BALL = {"ball": {"id": 1, "fields": [{"name": "flags", "type": "u8"},
                                     {"name": "x_px", "type": "i16"},
                                     {"name": "cam_ms", "type": "u32"}]}}
tx = Sender.open_auto(BALL, baud=115200, min_period_s=0.01)   # 限速 100 Hz，超出的调用直接丢
print(tx.device, tx.reason)
while True:
    x = detect()                                              # 你的识别
    tx.send("ball", flags=1 if x is not None else 0, x_px=x or 0, cam_ms=now_ms())
```
- 有 PyYAML 的板子可以直接读通道定义：`Sender.from_board("boards/maixcam2-vision/board.yaml", transport)`。
- 整数超范围自动截断（不会因为一帧坏数据抛异常让识别线程退出）；通道超过 64 字节在构造时报错。
- `tx.heartbeat()`：协处理器自己的心跳，MCU 可据此判断“视觉掉线”并降级。

K230（MicroPython）：
```python
from dzsend import DzSend
tx = DzSend.open_uart(uart_id=2, baud=115200)
tx.send(1, [("u8", 1), ("i16", 320), ("u32", 1234)])    # 顺序 = board.yaml fields
```
