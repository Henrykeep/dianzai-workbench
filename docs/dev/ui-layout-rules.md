# 界面整壳布局规则（v7）

目的：每页一眼知道“这一步干什么、主按钮在哪、结果在哪、下一步去哪”。好看是结果，逻辑是前提。
出处见 docs/参考来源.md「界面整壳布局规则」。`make check` 里的 tools/check_ui_layout.py 守 §7 的两条硬规则。

## 1. 整壳（所有页共用，VS Code 的容器分工）
```
┌ 左侧导航 ┬ 顶栏：连接胶囊 ……… 排障 · 工具箱 │ 急停 · 解除 ┐
│ 品牌      ├──────────── 页面区（按页型布局，见 §3）──────────┤
│ 8 步      │                                                   │
│ 提示/收起 └ 状态栏：链路 · 心跳 · 告警 ……… 记录 · 回放 · 侧车 ┘
```
- 顶栏只放全局的东西：连接胶囊、排障、工具箱、急停。某一步专用的按钮不准上顶栏。
- 左侧导航 `aside.nav #steps` 是唯一的页导航（v9 起取代顶栏时间线）：图标 + 步名；高亮 + 左侧色条 = 当前页，描边小圆点 = 建议下一步，淡绿 ✓ = 已走过；底部是下一步提示和「收起」。宽 200px，收起 56px；窗口 ≤1500px 自动收起。
- 急停永远在右上角、红色、全局快捷键 Space / Esc（Esc 永远是急停，任何对话框都不拿 Esc 关闭，靠右上角 × 和点框外）；“解除”紧挨着它。红色不用于其他按钮。
- 状态栏只读，不放操作（回放进度条例外，它属于记录）。

## 2. 层级：一页一个主任务
- 每页只有一个主按钮（黄铜填充色），放在主任务区域的左上（实况页，紧挨结果）或卡片右下（向导页，读完再按）。
- 结果（读数、曲线、表格）放页面中央最大的区域；历史放结果正下方；建议放右栏，并且只有“采纳 / 驳回”两个动作。
- 次要动作收进「更多…」菜单（同一区域内），不属于任何一步的工具进工具箱，“回到过去”的操作全部进「回到…」。
- 标签页只用于同一区域里互斥且同级的视图（参数 / 保护 / 快照）。某个标签只在一步有用，就只在那一步显示。

## 3. 三种页型
| 页型 | 页 | 骨架 |
|---|---|---|
| 向导页 | 项目、烧录、标定、封箱 | 居中单列（≤960px），标题 20px + 一句说明；每步一张卡片：标题 → 输入 → 输出，主按钮在卡片右下；确认才写文件 |
| 实况页 | 模块、联调、调参 | 左 参数/收发（撤销/下发固定在底）│ 中 主操作条 + 读数 + 主图，历史在下 │ 右 建议 + 提问 |
| 验收页 | 评分（封箱的检查清单在对话框） | 中 实况曲线 │ 右 评分矩阵 → 选中项的跑 N 轮与证据 |

## 4. 设计变量（app/ui/src/tokens.css 是唯一来源）
- 字号 4 级：12 / 14 / 20 / 40；间距 8 的倍数（细节 4）；面板间 8px，圆角 12（面板）/ 8（控件）。
- 文字 3 级对比：ink / text / muted。底色 s1 < s2（面板）< s3（卡片）。
- 唯一强调色黄铜 = 意图（设定值、待下发、提议、主按钮）；ok/warn/crit 只表示状态；红只给急停和故障。
- 深色、浅色、高对比三套主题共用同一组变量名。

## 5. 状态
- 未连接：实况页主图位置显示空状态，告诉用户“在左上角连接板子”，不显示假数据。
- 加载：按钮自身进入忙碌态，不弹全屏遮罩。
- 错误：说清发生了什么、怎么修，给出去处（自检 / 按症状排查）；不道歉、不含糊。
- 通知：toast 只报结果（已下发、已保存）；需要处理的告警进状态栏告警条，并能确认。
- 侧车断开：顶部黄色横幅，持续到恢复。

## 6. 对话框、工具箱、设置、快捷键
- 对话框：标题 → 说明一句 → 表单 → 按钮行（主按钮用黄铜填充，取消/关闭放最后）；只做一件事。
- 工具箱按类分组（测量、串口、帧格式、记录、协处理器、设置），每类一个小标题。设置（大模型、主题）只在工具箱。
- 快捷键写在按钮上的 kbd 里：Space/Esc 急停、⌃O 连接、⌃↵ 下发、⌃S 存快照、T 标 t0、P 暂停、/ 筛选参数。

## 7. 门禁（tools/check_ui_layout.py）
1. app/ui/src 下除 tokens.css 外的样式不许写颜色字面量，只用变量。
2. 每个区域顶层可见按钮数有上限（顶栏 6、调参操作条 3、主图工具条 2、左栏每个标签页 2、撤销/下发 2、建议栏 2），超了就收进「更多」或工具箱。时间线步骤栏不计。
入口唯一性仍由 tools/check_entrypoints.py 守（docs/dev/entrypoints.yaml）。

## v9 更新（依据 [design-decisions.md](design-decisions.md)）
- 字号收成 5 级：12 / 14 / 16 / 20 / 32（`--t-xs/sm`=12、`--t-md`=14 正文、`--t-lg`=16、`--t-h`=20、`--t-xl`=32）。
- 新增 `--w-nav:200px`、`--w-nav-folded:56px`、`--h-nav-item:32px`；`--h-top` 60→48。
- 时间线移到左侧可折叠导航；`.app` 用 `margin-left` 让位，网格列不变。
- 对话框统一右上角 ×（`.dlg-x`）+ 点框外关闭；Esc 留给急停。
- 最低支持分辨率 **1366×768**；每个改动的页面须在 1366×768 与 1920×1080 各截一张图验收，不允许截断或重叠。≤1500px 宽时左侧导航自动收起为图标。
- 层级靠间距和分隔线区分：区块之间 `--sp5`/`--sp6` 间距 + 1px `--hair` 分隔线；表面色只用 `--s0..s3` 四级，不靠细微灰度差。
