# 19 赛题覆盖矩阵（控制类）

方法参考 LP-MSPM0G3507_freertos_firework 的《历年题目与框架功能缺口分析》（MIT，见 参考来源.md）：按历年赛题列所需能力，对照本仓库现状标 **有 / 部分 / 缺**，用来排模块优先级。

> **题名与年份凭记忆整理，未逐条对照官方题目原文，使用前请核对。** "有"指仓库里有模块且 make test 覆盖，不代表实机验证过。
