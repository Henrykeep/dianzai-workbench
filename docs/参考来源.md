# 参考来源汇总

借鉴方式分两种（2026-10-29 起）：
- **直接使用**：队友/开源组项目的代码可以直接搬来用，注明来源即可。搬来的文件放 `third_party/vendored/<来源>/`，原样附 `LICENSE`，写 `SOURCE.md`，每个代码文件头写 `Source: <repo>@<commit> <path>`；`tools/check_vendored.py`（`make check`）强制检查。GPL/AGPL 代码一律放这里隔离（MIT/Apache 的单文件、单函数可以直接放进对应模块，文件头同样写 Source:，并在下表登记），通过薄适配层调用，删目录只影响适配层。说明见 `third_party/vendored/README.md`。
- **思路借鉴、代码自写**：文件注释里写"参考 …"，并在下表登记。

不整段粘贴巨石文件（如 5102 行的单文件），只搬能独立成块的部分并改造成本仓库分层。链接可达性于 2026-10-28 检查（Asia/Shanghai）。
