# 06 新增一块板卡

> 标注约定：**【已实测】** = 本仓库在 PC 上用测试/编译实际跑过（2026-10-28，Asia/Shanghai）；**【未验证】** = 设计意图或推断，尚未在真实硬件上做实验。实验是检验真理的唯一标准——【未验证】的内容上板前不要当结论。

1. 判断芯片系列是否已有移植层：STM32 → **只用 `stm32-cubemx`**（`stm32f4-hal` 已冻结，只服务天空星 HAL 版与 RM C 型两块存量板，新板用它会被 validate_board 拒绝）；MSPM0 → `mspm0-driverlib`（预留）；没有就新建 ports/<系列>，实现 pal.h 全部函数（不支持的返回 DZ_ENOTSUP），并通过 `apps/port_selftest`。
2. 建 `boards/<厂商-型号>/board.yaml`（schema：`schema/board.schema.json`）。STM32 用 CubeMX 时由 ioc_import 生成（05）；MSPM0 由 syscfg_import 生成（10）。
3. **不确定的引脚/时钟一律写 `TODO`**，并在 `todo:` 列表说明待核实什么。gen_board 拒绝生成含关键 TODO（如 hse_hz）的固件——宁可编不过，也不要拿猜的值上板。
4. `python3 tools/validate_board.py boards/<板>/board.yaml`，`make check`。
5. `make BOARD=<板> APP=port_selftest` → 上板：LED 闪、LINK 串口回显、定时器周期。把结果写进 board.yaml 注释和硬件路线图（标【已实测】+日期）。
6. 应用层不改一行：`make BOARD=<板> APP=motor_speed_demo`。

- 【已实测】换板示例：同一 motor_speed_demo 在 host-sim / skystar / skystar-cubemx 上编译通过；dji-rm-c 在临时填 HSE=12 MHz 时编译通过（已撤回）。
- 【未验证】以上任何板子的上板运行。
