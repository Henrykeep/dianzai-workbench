## 桌面工作台
7. **断线时是否自动急停**：现在板端只有 car_2wd 的 cmd_timeout_ms（收不到速度命令就刹车）；PC 断线不会主动发急停（发不出去）。是否要求所有应用实现“心跳超时 → 安全态”？建议要，但改动在固件，等你确认。
8. **打包版如何拿到 schema**：现在靠仓库 build/ 或 ~/.dzbench/schemas/。更彻底的方案是板端支持“读参数名/范围”（类似 MAVLink PARAM_VALUE 带名字、PX4 component metadata），代价是 Flash 和协议复杂度。
9. **Windows 仿真**：host-sim 的 --stream 用了 POSIX 时钟/stdin；要在 Windows 上也能选仿真板，需要给 host-sim 加 Win32 分支或在侧车里纯 Python 仿真。哪种？
10. **多窗口端口冲突**：两个工作台同时开时，第二个侧车绑 8765 失败，界面会连到第一个的侧车。要不要改成随机端口 + Tauri 注入？
11. **参数写回工程**：现在快照只在本机 ~/.dzbench；是否要“写回 project.yaml / app.yaml”按钮（会改源码，需要你同意格式）。
12. **自动波特率候选顺序**：460800 优先是按工作台各板默认；若队里常用 115200，可调到第一位以缩短连接时间。
