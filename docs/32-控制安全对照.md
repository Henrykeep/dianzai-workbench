## 极性自检（标定第 0 步）
铁律：Kp、限幅是放大器，修不了方向错。调参前先确认三处符号——传感器轴、误差极性、执行器方向——再加控制器增益为正。
`app/sidecar/dzbench/agent/polarity.py`（侧车 WebSocket op `polarity_check`）只读遥测窗口判读，不发任何指令：

1. **手推（观察模式）**：执行器不出力（急停或断电机电源），人把被控量往约定的 + 方向推，录 2–3 s。
   `step=push, y=被控量, e=误差通道, u=控制器输出通道` → 传感器轴（读数涨没涨）、误差极性（e 随 y 减 = e=sp−y）、控制器符号（u 随 e 增）。
2. **点动**：开环小幅 +u / 0 / −u / 0（或手动给 PWM），`step=jog, y, u, u_min` → 读数随 u 的方向；正反两段要一致，没动或矛盾时提示死区/间隙/限位。
3. 带上 `signs` 要结论：负反馈 → 可以调参；正反馈 → 指出哪一处反了（传感器反不会冤枉执行器；两处都反、两负得正时也提醒改回约定）。

测试：app/sidecar/tests/test_polarity.py（一阶对象 + P 控制器造数据：正确、执行器反、误差写反、负增益、传感器反、两处都反、死区/弱数据判不了，8 项）。
