# capfreq — 输入捕获测频 / 占空比  `v1.0.0`

喂边沿时间戳（定时器捕获值），N 个整周期平均 → 频率（毫赫兹）+ 占空比；断信号超时报“无信号”；处理 16 位计数回绕。
信号整形（比较器 / 施密特）和定时器捕获配置归 CubeMX/SysConfig，在捕获中断里调 `capfreq_edge()`。

- 精度：±1 tick 量化误差 / N 个周期。1 MHz 计数、N=8、1 kHz 信号 → 误差约 0.0125%。
- 低频（单周期超过计数器一圈）：把溢出次数并进高位，喂扩展计数并设 wrap=0。
- 高频（几十 kHz 以上，中断跟不上）：改用“门控计数”（定时器外部时钟计 1 s 内边沿数），本模块不适用。
