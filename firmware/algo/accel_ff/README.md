# 加速度前馈  `v1.0.0`

载体加速度 → 抵消惯性所需倾角（小角近似 θ≈a/g），带增益、死区（边沿连续）、失效保护（无效/NaN/超限 → 0）、输出限幅。

- 接口：`accel_ff_deg(cfg, a_mps2, valid)`；来源选择与超时判断留给调用方（例：examples/2026H_ball/subsys/ball/ball.c 编码器差分 / IMU 二选一）
- 典型：移动底盘上的球杆/平衡板、随车云台；输出加到反馈环的角度指令上
- 自检：`accel_ff_selftest()`；tests/host/test_ctrlparts.c

## 验证状态
- **已实测（PC 主机）**：换算系数、死区连续、NaN/超限/无效置 0、限幅、gain=0 关闭
- **[未测]**：实车上前馈是否改善小球偏移（2026H 默认 ff_gain=0）

## 参考来源
- 加速度前馈/倾角补偿为常规做法（参见 PX4 的 feed-forward 思路），代码自写；从 2026H 例题提取，行为不变。
