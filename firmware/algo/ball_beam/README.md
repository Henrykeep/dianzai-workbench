# ball_beam — 单轴球杆控制器

α-β 估计 + 超前预测 + 位置→速度→角度串级 + 条件积分 + 限幅/斜率 + 丢球处理。输入相对中心的像素，输出相对水平的摆杆角（°）。

| 设计 | 来源 |
|---|---|
| α-β 滤波（α 0.55、β 0.20）、70 ms 超前 | P2 工程 `fun.c` 的设计思路（自研，重写） |
| 串级 pos_k/vel_max/vel_k、积分“新样本才积、变号衰减”、hold/timeout | P1 工程 `ball_balance.c` 的结构（重写） |
| α-β 跟踪器理论、稳定域 0<β<4−2α | P. R. Kalata, “The Tracking Index”, IEEE TAES 1984 |

- 参数（P1 普通档，**来自非最终参赛代码，未验证**）：pos_k 0.72、vel_max 320 px/s、vel_k 0.016 °/(px/s)、angle_max 5.5°、rate 220°/s、ki 0.055、i_zone 55 px、i_max 2.5°、hold 120 ms、timeout 600 ms。快档 0.86/420/0.018/6.5°/320°/s。
- 未收：P2 的“静止时 D 降到 30%”“近处增益三角提升”——串级里速度环本身就起 D 的作用，先不叠加，调参需要时再加。
- 【已实测】主机单测：参数校验、α-β 对匀速运动的收敛、超前方向、积分区/变号衰减/限幅、斜率、hold/lost 状态与回零、乱序样本。
- 【未验证】实物闭环。
