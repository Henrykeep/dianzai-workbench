# α-β 观测器  `v1.0.0`

常速度模型下从位置测量估计位置和速度，可以外推、带野值门限。用于视觉钢珠位置/速度（替代差分 + 低通），以及编码器低速时的速度估计。

- 接口：`abobs_init/abobs_update/abobs_predict/abobs_reset`
- 自检：`abobs_selftest()`；tests/host/test_vision.c

## 验证状态
- **已实测（PC 主机）**：匀速收敛、噪声下的速度方差比差分小、门限丢弃野值、外推超时清零
- **未验证**：实机

## 参考来源
- 标准 α-β 滤波（Kalata 1984 等教材公式），自写。稳定条件 0<α≤1、0≤β<4−2α。
